# Aplicaciones Móviles - Android Studio Projects

Repositorio con proyectos desarrollados durante la materia de Aplicaciones Móviles en la Escuela Superior de Cómputo (ESCOM), impartida por el profesor Sigfrido.

## Descripción

Este repositorio contiene 12 aplicaciones Android desarrolladas como parte del curso de Aplicaciones Móviles. Los proyectos abarcan desde conceptos básicos de UI hasta integración con hardware (Bluetooth, NFC) y comunicación con dispositivos externos (Arduino).

## Índice de Proyectos

| Proyecto | Descripción |
|---|---|
| [AfinadorGuitarra](./AfinadorGuitarra/README.md) | Afinador de guitarra con reproducción de notas mediante MediaPlayer |
| [AppCanvas](./AppCanvas/README.md) | Dibujo con Canvas para graficar funciones seno y coseno |
| [AppCirculoBarra](./AppCirculoBarra/README.md) | Aplicación con Fragmentos y dibujo en Canvas |
| [AppSpinner](./AppSpinner/README.md) | Ejemplo básico de uso de Spinner (lista desplegable) |
| [EjercicioOrden](./EjercicioOrden/README.md) | Ordenamiento de números utilizando el algoritmo Burbuja |
| [EqSegGrado](./EqSegGrado/README.md) | Calculadora de ecuaciones de segundo grado |
| [EqSegundoGradoFragmentos](./EqSegundoGradoFragmentos/README.md) | Calculadora de ecuaciones de segundo grado usando Fragmentos |
| [IntentosSegundoGrado](./IntentosSegundoGrado/README.md) | Calculadora de ecuaciones de segundo grado con paso de datos entre Activities |
| [NFCEditor](./NFCEditor/README.md) | Lectura y escritura de etiquetas NFC |
| [ServoMotorAndroid](./ServoMotorAndroid/README.md) | Control de servo motor mediante Bluetooth (Arduino) |

## Tecnologías Utilizadas

- Android SDK: API 24+ con target API 33
- Java: Lenguaje de programación
- AndroidX: Librerías modernas
- Material Design: Componentes UI
- Bluetooth, NFC, MediaPlayer, WebView, Canvas, Fragments, Activities

## Requisitos

- Android Studio (versión recomendada: 2022 o superior)
- JDK 8 o superior
- Dispositivo Android API 24+ o Emulador
- Para proyectos con Bluetooth: Dispositivo con Bluetooth
- Para proyecto NFC: Dispositivo con NFC

## Instrucciones de Uso

1. Clona este repositorio
2. Abre Android Studio y selecciona "Open an Existing Project"
3. Sincroniza Gradle
4. Ejecuta en emulador o dispositivo físico
