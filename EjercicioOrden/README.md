# EjercicioOrden

## Descripción

Aplicación Android que recibe una cadena de números y aplica algoritmos de ordenamiento. Implementa el método de burbuja para ordenar los dígitos y luego invierte el arreglo para realizar cálculos.

## Características

- Entrada de números por usuario
- Implementación del algoritmo de ordenamiento Burbuja
- Inversión de arreglo
- Cálculo de diferencia entre número ordenado invertido y número ordenado
- Visualización de resultados paso a paso

## Tecnologías

- Java
- Android SDK
- Algoritmos de ordenamiento

## Estructura del Proyecto

- MainActivity.java: Activity con lógica de ordenamiento
- ctivity_main.xml: Layout con EditText, Button y TextView

## Funcionamiento

1. El usuario ingresa una secuencia de dígitos en el campo de texto
2. Se convierte cada dígito a un array de enteros
3. Se aplica el algoritmo de burbuja para ordenar ascendentemente
4. Se invierte el arreglo ordenado
5. Se muestra: número invertido, número ordenado y la diferencia entre ambos

## Algoritmos Implementados

- **Burbuja (Bubble Sort)**: Ordenamiento comparativo por intercambios
- **Inversión de arreglo**: Invierte el orden de elementos

## Requisitos

- Android API 24+
